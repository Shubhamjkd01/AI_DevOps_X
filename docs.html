Laptop Setup & Customization Guide

Complete step-by-step instructions to clone, configure, customize, and run AIDEVOPS locally on your personal laptop or development workstation.

💻 What You Need on Your Laptop (Prerequisites)

SETUP TIME: ~4 MINUTES

Before starting, make sure you have the following installed on your machine:

🐍 Python 3.10+

🐙 Git & GitHub Account
For cloning repo, setting up webhooks, and pushing automated fix PRs.

🚀 Step-by-Step Laptop Setup Walkthrough

1
Clone the Repository to Your Laptop
Open PowerShell, CMD, or Terminal on your laptop and clone the official project repository:
git clone https://github.com/Shubhamjkd01/AI_DevOps_X.git
cd AI_DevOps_X/github_agent_backend
2
Create a Virtual Environment & Install Dependencies
Isolate your dependencies to keep your system clean:
# On Windows (PowerShell):
python -m venv venv
.env\Scripts\Activate.ps1

# On macOS / Linux:
python3 -m venv venv
source venv/bin/activate

# Install all required libraries:
pip install -r requirements.txt
3
Configure Your Secret Keys in .env
Create a file named .env in the github_agent_backend folder (you can copy .env.example if present): 
# 1. Get free Gemini Key from: https://aistudio.google.com
GEMINI_API_KEY="AIzaSyYourGeminiApiKeyHere"

# 2. Get GitHub Token from: GitHub -> Settings -> Developer Settings -> Personal Access Tokens
# Permissions required: "Actions: Read" and "Pull Requests: Read & Write"
GITHUB_TOKEN="ghp_YourGitHubPersonalAccessToken"

# 3. Create any random secret string (e.g. 16+ chars)
GITHUB_WEBHOOK_SECRET="super_secret_webhook_passphrase_987"

# 4. Local Server Ports
SERVER_PORT=7860
DASHBOARD_PORT=8501
4
Expose Your Laptop Port to GitHub (Ngrok / Cloudflare)
Because your laptop is behind your home Wi-Fi or router, GitHub's cloud servers cannot directly ping localhost:7860. Use ngrok (free) or localtunnel to create a secure bridge: 
# Install ngrok from ngrok.com (or via choco / brew)
# In a new terminal window, run:
ngrok http 7860
Ngrok will give you a public Forwarding URL like: https://3a1b-103-21-54-1.ngrok-free.app.
Your GitHub Webhook URL will be: https://3a1b-103-21-54-1.ngrok-free.app/webhook/github
5
Connect GitHub Webhook to Your Repository
Go to your repository on GitHub:
  1. Click Settings → Webhooks → Add Webhook
  2. Payload URL: Paste your ngrok URL with /webhook/github (e.g. https://your-ngrok.ngrok-free.app/webhook/github)
  3. Content type: Select application/json
  4. Secret: Enter the exact same secret you put in your .env file (GITHUB_WEBHOOK_SECRET)
  5. Which events would you like to trigger this webhook? Select "Let me select individual events" ✓ Check "Workflow runs".
  6. Click Add Webhook (Active green checkmark appears).
6
Launch Backend Server & Interactive Dashboard
Open two terminal tabs on your laptop to run both the API and the UI:
# Terminal 1: Run FastAPI Webhook Receiver Agent
python -m uvicorn server.app:app --host 0.0.0.0 --port 7860 --reload

# Terminal 2: Run Streamlit Analytics Dashboard
python -m streamlit run dashboard.py --server.port 8501
Your dashboard is now live at http://localhost:8501 and ready to receive and heal CI failures in real-time!
7
Test Your Laptop Setup (Instant Dry-Run)
You don't need to wait for a real GitHub failure to verify everything works! We included a built-in mock failure generator: 
# In a new terminal tab, run:
python scripts/test_webhook_local.py
Watch Terminal 1 parse the error, consult episodic memory, invoke Gemini with AST checks, and log the autonomous patch.

🔧 Laptop Setup Troubleshooting & FAQ

❌ Webhook returns "401 Unauthorized"
Fix: The secret you typed in GitHub Webhooks does not match the GITHUB_WEBHOOK_SECRET inside your .env file. Update both so they are identical strings.
❌ GitHub PR creation fails with "403 Forbidden"
Fix: Your Personal Access Token is missing permissions. Go to GitHub Token settings and ensure Pull Requests: Read & Write and Contents: Read & Write are checked.
❌ "Address already in use" on port 7860 or 8501
Fix: Another process is occupying the port. Either kill the previous python process or change --port 7861 or --server.port 8502.
❌ ngrok session expires after 2 hours
Fix: Create a free account at ngrok.com to get a permanent authtoken and static free domain, or deploy the backend to a cloud VPS like DigitalOcean or HuggingFace.
